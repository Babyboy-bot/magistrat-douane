# Sons de Notification

## Fichiers disponibles

- `notification-sound.mp3` - Son par défaut (info)
- `notification-success.mp3` - Son succès
- `notification-warning.mp3` - Son avertissement  
- `notification-error.mp3` - Son erreur

## Comment ajouter vos propres sons

1. **Trouvez des fichiers MP3** gratuits ou créez les vôtres
2. **Remplacez les fichiers** dans le dossier `public/`
3. **Assurez-vous** que les fichiers sont nommés exactement comme ci-dessus

## Sources de sons gratuits

- [Zapsplat](https://www.zapsplat.com/) - Sons gratuits
- [Freesound](https://freesound.org/) - Sons sous licence
- [Pixabay](https://pixabay.com/sound-effects/) - Effets sonores gratuits

## Configuration

Le volume est réglé à 30% par défaut pour ne pas être trop agressif.

Les sons sont joués automatiquement lors des notifications WebSocket selon leur type.
